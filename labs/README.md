# Labs

Infraestructura local para ejercicios: el tutor genera `labs/<nombre>/` con lo
necesario (p. ej. `docker-compose.yml`) + README con pasos de verificación
cuando un tópico lo requiere (PostgreSQL con pgvector, Langfuse self-hosted u Ollama vía docker-compose).

Apaga los labs al terminar la sesión para liberar recursos.
