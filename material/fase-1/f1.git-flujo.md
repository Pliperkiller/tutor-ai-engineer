# f1.git-flujo — apuntes

## Sesión 4 (2026-07-29) — branches, merge y conflictos (flujo local)

### Por qué existen las branches
- Antes: carpetas duplicadas (`proyecto_v2_FINAL/`) o todos commiteando a la
  misma línea de historia, pisándose.
- Una **branch** es una línea de historia paralela que nace de un commit.
  Trabajas sin romper `main`; **merge** vuelve a juntar las líneas.

### Comandos del día
```bash
git switch -c nombre       # crear branch y saltar a ella
git switch main            # cambiar de branch
git merge otra-branch      # traer los cambios de otra-branch a donde estás
git log --oneline --graph --all   # ver la historia dibujada
git branch --merged main   # qué branches ya están fusionadas
git config --global core.editor vi   # editor por defecto de git
```

### Fast-forward vs merge commit — LA regla del día
- **Una branch es solo un puntero a un commit**, no una copia de archivos.
- Merge **sin divergencia** (main no tiene commits propios desde que nació la
  branch): git no combina nada, solo **adelanta el puntero** → `Fast-forward`.
  Cero commits nuevos; la historia queda en línea recta.
- Merge **con divergencia** (ambas líneas tienen commits propios): git combina
  y el resultado vive en un **commit de merge con dos padres** (el rombo del graph).

```
sin divergencia:            con divergencia:
A──B  ← branch              A──B   ← main
↑                            \  \
main (se adelanta a B)        C──M ← commit de merge (2 padres)
```

### Conflictos
- Ocurren cuando dos branches editaron **la misma línea desde el mismo punto
  de partida**. Git compara texto, no significado: cuál valor es "correcto" es
  una decisión de negocio que no vive en ningún commit → te pregunta a ti.
- Marcadores: `<<<<<<< HEAD` (tu lado), `=======`, `>>>>>>> branch` (el otro).
- Resolver = editar el archivo dejando el contenido final decidido — un lado,
  el otro, **o una mezcla que ninguna branch tenía** — sin marcadores, y luego
  `git add` + `git commit`.
- El mensaje de ese merge commit debe **documentar la decisión y el porqué**
  (error del día: quedó el mensaje por defecto `Merge branch '...'`).
